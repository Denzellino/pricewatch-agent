🔍 О проекте PriceWatch Agent

PriceWatch Agent — это автоматическая система мониторинга цен конкурентов для e-commerce бизнеса. Сервис помогает отслеживать изменения цен на товары у конкурентов и мгновенно получать уведомления в Telegram.

📋 Возможности

  • Автоматический парсинг цен с сайтов конкурентов
  • История изменений цен
  • Уведомления в Telegram при изменении цены
  • Гибкие тарифные планы (от 5 до 1000 товаров)
  • REST API для интеграции
  • Аналитика и отчёты

🛠 Технологии

Backend: Python, FastAPI, SQLAlchemy, SQLite
Frontend: HTML5, CSS3, Vanilla JavaScript
Security: JWT токены, bcrypt хеширование
Deployment: Docker, Gunicorn, Nginx

🚀 Планы развития

В ближайших версиях:

  • Интеграция с ЮKassa для оплаты
  • Telegram бот для управления
  • Поддержка PostgreSQL
  • Расширенная аналитика
  • Мобильное приложение
