# Changelog

## [0.1.0] - 2026-09-16

### Добавлено
- ✅ Авторизация и регистрация пользователей (JWT)
- ✅ Дашборд для управления товарами
- ✅ Страница тарифных планов (Demo, Basic, Pro, Enterprise)
- ✅ REST API endpoints:
  - `/auth/register` — регистрация
  - `/auth/login` — вход
  - `/auth/me` — информация о пользователе
  - `/products/` — CRUD товаров
- ✅ База данных (SQLAlchemy + SQLite):
  - Таблицы: User, Product, Store, PriceHistory, Subscription
- ✅ Фронтенд (HTML/CSS/JS):
  - Страницы: login, register, dashboard, pricing, about
- ✅ Система подписок с лимитами товаров
- ✅ Парсинг цен (базовая версия)
- ✅ Telegram бот (базовая версия)

### Изменено
- Обновлена структура проекта
- Улучшена документация

### Известные проблемы
- Интеграция с ЮKassa в разработке
- Парсинг работает только с некоторыми сайтами
- Telegram бот требует настройки
